# User Stories

1. As a user, I want to add a task to a list, so that I can keep track of what I need to do.

2. As a user, I want to mark a task as complete, so that I can see my progress at a glance.

3. As a user, I want to filter tasks by status (all / completed / incomplete), so that I can focus on what's left.

4. As a user, I want to delete tasks I no longer need, so that my list stays relevant.

5. As a user, I want to submit a contact form, so that I can send feedback about the app.
